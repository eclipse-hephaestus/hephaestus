This independent community implementation is proposed for a Hephaestus
documentation-assistance pilot. It provides pinned source ingestion, requirement
lookup, local search, cited answers and explicit snapshot comparison.

**Maturity:** existing S-CORE implementation; Hephaestus integration and
maintainer acceptance pending.

Review the [architecture, evidence and proposed pilot](../../docs/docs/contributions/s-core-docs-assistant.html).
The public [implementation baseline](https://github.com/jnsagai/s-core_bot/tree/72c1fb2cab280e6835513b046013e5abea066c3a)
is available separately under Apache-2.0. Model and corpus licenses remain distinct.
