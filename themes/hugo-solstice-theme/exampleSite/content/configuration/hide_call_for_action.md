---
title: "hide_call_for_action"
description: "Hides the call-to-action button site-wide."
type: "doc_param"
category: "call to action"
param_type: "boolean"
accepted_values:
  - "`true`"
hide_sidebar: true
---

When not set (or set to any value other than `true`), the parameter is ignored and the CTA button is shown on all pages.

## Example

```toml
[Params]
  hide_call_for_action = true
```
