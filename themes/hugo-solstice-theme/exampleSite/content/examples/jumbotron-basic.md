A jumbotron renders automatically as soon as `headline` is set in the page
front matter. Adding a `tagline` provides a short supporting line beneath it.

```yaml
headline: "Hugo Solstice Theme"
tagline: "The open-source platform for Eclipse Foundation sites."
```
