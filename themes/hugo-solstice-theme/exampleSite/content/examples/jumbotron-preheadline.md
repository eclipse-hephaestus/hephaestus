`preheadline` renders above the main headline in a smaller style. It is
typically used to label the type of page (announcement, event, section name,
etc.).

```yaml
preheadline: "Announcement"
headline: "Solstice 3.1 is now available"
tagline: "New components, refreshed documentation, and ESM support."
```
