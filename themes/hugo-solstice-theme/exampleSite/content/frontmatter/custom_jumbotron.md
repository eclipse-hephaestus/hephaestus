---
title: "custom_jumbotron"
description: "Custom HTML content injected after the tagline inside the jumbotron. Using this together with `tagline` is not recommended."
type: "doc_param"
category: "jumbotron"
param_type: "string"
accepted_values:
  - Any string value, including HTML markup
hide_sidebar: true
---

## Example

```yaml
custom_jumbotron: |
  <h1 class="margin-top-10">Guiding the Future of IDE Development</h1>
  <p class="margin-top-20">May 19, 2025 &mdash; 8AM–11AM PST</p>
```
