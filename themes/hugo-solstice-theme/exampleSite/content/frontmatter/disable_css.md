---
title: "disable_css"
description: "Disables all theme CSS on the page when set to `true`."
type: "doc_param"
category: "resources"
param_type: "boolean"
accepted_values:
  - "`true`"
hide_sidebar: true
---

When not set (or set to any value other than `true`), the parameter is ignored and CSS loads normally.

## Example

```yaml
disable_css: true
```
