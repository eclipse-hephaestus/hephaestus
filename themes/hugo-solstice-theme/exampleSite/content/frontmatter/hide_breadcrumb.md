---
title: "hide_breadcrumb"
description: "Hides the breadcrumb navigation on this page."
type: "doc_param"
category: "layout"
param_type: "boolean"
accepted_values:
  - "`true`"
hide_sidebar: true
---

When not set (or set to any value other than `true`), the breadcrumb is shown normally (unless hidden at the site level).

## Example

```yaml
hide_breadcrumb: true
```
