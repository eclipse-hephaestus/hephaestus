---
title: "hide_page_title"
description: "Hides the rendered `<h1>` page title."
type: "doc_param"
category: "layout"
param_type: "boolean"
accepted_values:
  - "`true`"
hide_sidebar: true
---

When not set (or set to any value other than `true`), the page title is shown normally.

## Example

```yaml
hide_page_title: true
```
