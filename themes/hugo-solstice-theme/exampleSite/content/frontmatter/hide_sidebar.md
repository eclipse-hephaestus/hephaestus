---
title: "hide_sidebar"
description: "Hides the main content sidebar on this page."
type: "doc_param"
category: "layout"
param_type: "boolean"
accepted_values:
  - "`true`"
hide_sidebar: true
---

When not set (or set to any value other than `true`), the sidebar is rendered normally.

## Example

```yaml
hide_sidebar: true
```
