---
title: "show_collapsible_menu"
description: "Shows the collapsible sidebar navigation menu on mobile viewports for this page."
type: "doc_param"
category: "navigation"
param_type: "boolean"
accepted_values:
  - "`true`"
hide_sidebar: true
---

When not set (or set to any value other than `true`), the parameter is ignored. Can also be enabled site-wide via the `show_collapsible_menu` site parameter.

## Example

```yaml
show_collapsible_menu: true
```
