---
title: "show_featured_footer"
description: "Shows the featured footer section at the bottom of the page."
type: "doc_param"
category: "layout"
param_type: "boolean"
accepted_values:
  - "`true`"
hide_sidebar: true
---

When not set (or set to any value other than `true`), the featured footer is hidden on this page.

## Example

```yaml
show_featured_footer: true
```
